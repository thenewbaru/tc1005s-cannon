# tc1005s-cannon

Juego Cannon de freegames, modificado para la evidencia de TC1005S (Actividad 2).

Owner del repositorio: Angel Barush (thenewbaru). Fork: Jaime Samuel García Manzano (krannyy).

## Contenido
- `cannon.py`: el juego.
- `README.md`: este archivo.

## Cómo correrlo
```
pip install freegames
python3 cannon.py
```
Se hace clic en la pantalla para disparar la bala hacia ese punto y se intenta pegar a los objetivos azules.
